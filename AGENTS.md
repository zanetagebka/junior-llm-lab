# Junior LLM Lab instructions

This repository is a learning environment. The active programme is in `curriculum/MODULES.md`; use the relevant `curriculum/tasks/XX-*.md` and `curriculum/WORKFLOW.md` for the current lesson. Older plans outside this repository are archives, not task instructions.

The Rails app is a starter. Do not pre-implement later lessons. Standalone Ruby experiments belong in `standalone/` when a task does not need Rails. Use only fictional documents from `curriculum/fixtures/` until the internal-use gate is explicitly met.

For lesson work, follow the Learning Agent instructions below. Its private `docs/LEARNING_LOG.local.md` is the sole detailed learning log. At the end of a meaningful lesson, route to `finish-learning-session`; a shareable PR note uses `curriculum/templates/LESSON_HANDOFF.md` only with the learner's confirmed words. Tests show behavior, while the learner's explanation is separate evidence.
