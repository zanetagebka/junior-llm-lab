# Task 19 — Product Experiment

**Module 10 — Product judgment**

**Lovable PoC:** Now use Lovable for its strongest role: rapidly test an improved Knowledge Assistant workflow with a real product hypothesis.

**Rails/Strategy:** Write the user problem, current workflow, non-AI baseline, AI hypothesis, metric, risks and smallest experiment. Implement only the smallest Rails change needed to test the hypothesis.

**Compare:** What did the prototype validate about user experience? What did it not validate about model quality, feasibility, security or economics?

**Gate:** Make a next-experiment recommendation from evidence, not attachment to the prototype.

## Completion

Follow the [lesson workflow](../WORKFLOW.md). Keep the Lovable change small, implement the agreed behavior in Ruby or Rails, show verification, and close the session in the private Learning Agent log.
